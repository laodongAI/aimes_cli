# Skill: 市场分析 (Market Analysis)

## Purpose / 目的与价值主张

系统性地分析市场结构，使用波特五力、PESTEL和SWOT框架，识别影响产品的外部力量。用于支持市场进入决策、战略规划或风险评估。

**核心价值**: 将复杂的市场环境转化为结构化的、可操作的分析，为产品决策提供证据支持。

## Input / 输入要求

**Works best with:** 要分析的产品、市场或战略决策
**Also useful:** 地理边界、时间范围、已知的竞争对手信息

**Example invocation:** `分析中端现场服务管理软件市场，支持市场进入决策，地理范围：北美，时间范围：未来12-24个月`

## Key Concepts / 核心概念

### 波特五力框架 (Porter's Five Forces)
行业盈利能力由五种结构性力量决定：
1. **竞争对手的威胁** - 现有竞争者之间的竞争强度
2. **新进入者的威胁** - 新竞争者进入的难易程度
3. **替代品的威胁** - 替代产品或服务的可用性
4. **买方议价能力** - 客户对价格和条款的影响力
5. **供应商议价能力** - 供应商对价格和条款的影响力

**证据要求**: 每个力量评级必须有**文档化的信号**支持，不能仅凭主观判断。

### PESTEL框架
宏观环境分析的六个维度：
1. **政治因素** (Political) - 政府政策、稳定性、贸易规则
2. **经济因素** (Economic) - 增长率、通胀、汇率
3. **社会因素** (Social) - 人口统计、文化趋势、生活方式
4. **技术因素** (Technological) - 创新、研发、自动化
5. **环境因素** (Environmental) - 气候变化、可持续性、资源稀缺
6. **法律因素** (Legal) - 合规要求、知识产权、劳动法规

### SWOT分析
内外部环境的四象限分析：
- **优势** (Strengths) - 内部的、当前的、有利因素
- **劣势** (Weaknesses) - 内部的、当前的、不利因素
- **机会** (Opportunities) - 外部的、未来的、有利因素
- **威胁** (Threats) - 外部的、未来的、不利因素

**关键交叉分析**: 
- **S-O交叉** (优势-机会): 哪些优势可以开发哪些机会
- **W-T交叉** (劣势-威胁): 哪些劣势会被哪些威胁利用

### 证据标签系统
所有分析点必须标注证据等级：
- **Fact** - 可验证的事实，有URL或数据源支持
- **Inference** - 基于事实的合理推断
- **Assumption** - 需要验证的假设

## Application / 应用流程

### Step 0: 定义分析范围

**Agent asks:**
"请提供以下信息以定义分析范围：

**产品/市场信息:**
- 产品或服务名称
- 目标市场或细分市场
- 地理范围
- 时间范围

**分析目的:**
- 这个分析用于支持什么决策？
- 主要受众是谁？"

### Step 1: 波特五力分析

**Agent asks:**
"让我们进行波特五力分析。我将为每个力量搜索相关信号：

1. **竞争对手的威胁** - 集中度、增长率、差异化、退出壁垒
2. **新进入者的威胁** - 进入壁垒、资本需求、近期进入者表现
3. **替代品的威胁** - 替代品采用、价格-性能轨迹、AI驱动的替代
4. **买方议价能力** - 买方集中度、转换成本、价格透明度
5. **供应商议价能力** - 供应商集中度、云/模型/平台依赖

请确认分析范围，我将开始搜索。"

```markdown

## Outputs / 输出物

- **波特五力分析报告** - 带证据和评级的结构化分析
- **PESTEL分析报告** - 宏观环境的6维分析
- **SWOT分析报告** - 内外部环境的4象限分析
- **综合结论与建议** - 基于所有分析的可操作建议
- **需要验证的假设列表** - 后续需要验证的关键假设

## Safety and permissions / 安全与权限

- 不自动执行任何破坏性操作
- 所有分析基于公开可获取的信息
- 不存储或传输敏感数据
- 所有证据来源必须是公开的、可验证的
- 保留用户对最终决策的控制权

## Failure handling / 失败处理

| 失败类型 | 必须执行的操作 |
|----------|----------------|
| 缺乏足够证据 | 明确标注为Assumption，并提供验证路径 |
| 证据来源不可用 | 使用Inference标签，并记录推理过程 |
| 分析范围不明确 | 请求用户提供更多上下文，不进行模糊分析 |
| 数据过期 | 标注证据的时间戳，建议重新分析 |
| 竞争对手信息缺失 | 使用行业基准数据，并标注为Inference |

## Completion criteria / 完成标准

- [ ] 所有五力都有明确的评级和证据支持
- [ ] PESTEL的所有6个维度都有分析
- [ ] SWOT的四个象限都有条目，且每个条目都有证据
- [ ] 交叉分析(S-O, W-T)已完成
- [ ] 综合结论包含具体的、可操作的建议
- [ ] 所有证据都有明确的标签(Fact/Inference/Assumption)
- [ ] 需要验证的假设列表已提供

**分析日期:** 2026-10-22 | **边界:** 北美中端市场 | **支持的决策:** 市场进入决策

### 1. 竞争对手的威胁 — 中等

- 信号: 产品差异化主要体现在移动端功能 — **Inference**
- 含义: 竞争激烈但市场在增长，差异化机会存在

### 2. 新进入者的威胁 — 弱
- 信号: 需要200万美元初始资本投入 — **Fact** ([创业成本分析, URL])
- 信号: 近3年只有2个新进入者，且都失败 — **Fact** ([Crunchbase数据, URL])
- 信号: 客户转换成本高，平均需要6个月迁移 — **Fact** ([客户调研, URL])
- 含义: 进入壁垒较高，新进入者威胁较低

... (其他力量分析)

### 6. 利润池
- 利润当前位置及挤压力量: 利润池位于高端企业级市场，主要受买方议价能力挤压 — **Inference**
- 结构趋势: 整体结构趋于收紧，AI驱动的自动化工具正在侵蚀低端市场 — **Fact**
- 对您的决策: 进入高端企业市场需要通过差异化的产品功能来抵抗买方议价能力；避免进入低端市场，因为AI替代品已经占据主导地位
```

## Common Pitfalls / 常见陷阱

### Pitfall 1: 无证据的评级
**Symptom:** "竞争对手威胁：强" 仅因为看起来拥挤
**Consequence:** 分析变成主观猜测，缺乏可信度
**Fix:** 每个评级都必须有文档化的信号支持，否则整个分析就是一个图表

### Pitfall 2: 忽略AI替代品
**Symptom:** 评估替代品时只考虑传统替代品
**Consequence:** 低估了AI对行业的颠覆性影响
**Fix:** 明确将AI驱动的替代品作为一个独立类别进行评估

### Pitfall 3: 混淆竞争对手与结构
**Symptom:** 列出谁在参与竞争（这是市场扫描的内容）而不是分析结构对所有参与者的影响
**Consequence:** 五力分析变成竞争对手列表
**Fix:** 五力分析的是利润率的物理学，不是名单

### Pitfall 4: 没有利润池结论
**Symptom:** 五个评级的力量但没有回答"利润去哪里？"
**Consequence:** 分析没有结论，缺乏行动指导
**Fix:** 利润池分析是整个分析的核心，必须明确说明

### Pitfall 5: 强行将结构套用于新兴类别
**Symptom:** 对尚未形成的类别进行力量评级
**Consequence:** 产生自信的噪音
**Fix:** 直接说"仍在形成中"，进行市场扫描，2个季度后重新评估
