# 需求与产品分析 Skill 部署及验收

## 根因
AIMES 主仓库的通用 Skill 注册表与 CLI 可部署资产是两个不同层次。CLI 初始化读取 src/aimes_cli/templates/skills/，不会自动把仓库根目录 skills/ 下的所有 Skill 复制到用户项目。因此，仅在根目录注册产品/需求 Skill 不足以使其在新项目中可用。

## 本次修复
- 将需求认知和产品分析入口 Skill 纳入 CLI 模板资产，随初始化部署。
- 在项目级 Skill 注册表中加入可部署路径和触发条件。
- 在治理 Core 中定义任务路由、输出契约、宿主 Skill 降级边界和证据要求。
- 增加初始化测试，检查 Skill 文件、注册表引用和 Core 路由一致。
- 保持用户自定义文件保护：已有注册表若被用户修改，不会被静默覆盖；升级会生成 proposed 候选供审查。

## 验收边界
自动化测试验证部署和静态路由一致性，不证明 ZCode、Trae Code 或其他 IDE/Agent 在运行时自动加载 Skill。运行时验收仍须针对具体产品版本、运行模式执行独立测试，并保存原始输出与证据。没有该证据时状态保持 UNKNOWN 或 NOT_RUN。
