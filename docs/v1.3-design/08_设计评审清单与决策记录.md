## 3. 阶段 0 验收

进入实现阶段前必须满足：

1. V1.3 总体设计经过审查，所有阻断性决策有结论；
2. 需求认知与知识复用的输入/输出 Schema 已批准；
3. Skill 注册表与现有 P01-P10 的映射已明确；
4. 评测案例基线、标注方法和硬门禁定义已明确；
5. CLI V0.1.0 源码、测试、打包与现有命令已审计；
6. 选定一个试点项目，记录实际 commit、Git 状态、工具版本和规则入口；
7. 未验证的能力保持 `UNKNOWN` 或 `IMPLEMENTED_UNVERIFIED`，不得提前标记 `VERIFIED`。
