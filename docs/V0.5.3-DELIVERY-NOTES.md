# AIMES CLI V0.5.3 交付说明

## 本次解决的问题

1. 交互式入口：在交互式终端只输入 `aimes`，进入主菜单；初始化/配置/预览流程逐步引导选择工具。默认先预览，选择实际写入时必须输入 `YES` 确认。
2. 独立运行方案：提供 Windows PyInstaller 构建脚本，EXE 将携带 Python 运行时和依赖，不再依赖激活项目 `.venv`。将整个 `dist-exe\aimes` 目录放在固定位置并加入用户 PATH 后，可从不同工作目录调用。
3. 原有显式命令保持兼容，适用于自动化脚本和 CI。

## 验证结果

- Python 单元测试：47 通过，0 失败（Linux / Python 3.13）。
- Windows EXE：本次环境不是 Windows，因此没有构建或验证原生 EXE。请在 Windows 上运行 `build_windows_exe.ps1`，并在新 PowerShell 窗口中验证版本、交互菜单以及从其他目录初始化项目的行为。

## 边界

- `--scope` 仍仅支持 `project`。
- EXE 路径需加入用户 PATH；“无需激活 venv”不等于无需安装/部署。
- ZCode/QCode 等标记为 manual 的适配器仍需要人工核验，不代表原生规则加载已被验证。
