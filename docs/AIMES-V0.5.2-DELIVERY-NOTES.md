# AIMES CLI V0.5.2 交付说明

## 交付范围

V0.5.2 以 V0.5.1 全量源码为基线，纳入 Google 对 V0.5.1 的四项建议，并合并 CLI 工程加固建议。保留原有 CLI、7 个 P0 Skills、追溯、证据、Context Pack、适配器和 14 个评测案例。

## 新增与调整

- 7 个 Skills 版本从 `0.2.0` 升级到 `0.3.0`，真实运行验证仍为 `UNKNOWN`。
- 新增共享输出正反例、上下文预算/文件选择计划协议、外部工具失败降级协议、审计追踪协议。
- 新增 `aimes evaluation run-mock`：对人工提供的 mock 响应执行字面匹配，明确不是模型评测。
- 新增 `aimes audit append` 和 `aimes audit validate`，提供本地 JSONL 审计事件与常见敏感字段脱敏。
- 改进 YAML/JSON 解析错误，提供行列位置和常见修复建议。
- 新增命令回归测试、统一评审与实施矩阵、历史兼容模块生命周期治理说明。

## 验证结果

- 单元测试：45 passed，0 failed。
- Skill 注册表：7 个，0 errors，0 warnings。
- 提示词评测集：14 个案例，0 errors，0 warnings。
- Mock Runner：6 个 fixture 案例通过词面检查；不代表真实模型效果。
- 审计追加/校验冒烟通过。
- Wheel 构建与隔离目标目录安装冒烟通过。

## 重要限制

- 尚未接入真实模型 API 或本地模型；未运行真实提示词评测。
- Mock Runner 使用精确子串匹配，不能判断语义等价或推断模型能力。
- 文件选择计划目前是规范和提示词协议，不会在 IDE 侧强制拦截实际文件读取。
- 审计事件需由调用方显式写入；日志没有自动防篡改保证，也不会自动捕获全部 IDE/模型活动。
- 尚未实现完整的 Skill 动态执行引擎、多 Skill 自动编排和扩展式交互向导。
- 未在 Windows 11 或真实 IDE/Agent 环境验证。
