# AIMES CLI V0.5.2 统一评审与实施计划

## 1. 决策摘要

本计划合并两组评审：一组关注 V0.5.1 提示词/Skill 资产的 Few-Shot、上下文预算、工具失败降级和动态评测；另一组关注 CLI 工程成熟度，包括命令契约回归、Schema 错误诊断、交互式向导、V1.3 模块化与审计追踪。V0.5.1 的七个 P0 Skills 和既有命令行为作为回归基线。

## 2. 采纳矩阵

| ID | 建议 | 决策 | 本版本处理 | 状态/边界 |
|---|---|---|---|---|
| G051-01 | Few-Shot 正反例 | 采纳并共享化 | 新增输出示例库；七个 Skill 引用统一示例和契约校验要求 | 已完成静态资产；示例本身不保证模型服从 |
| G051-02 | 上下文预算/文件选择计划 | 采纳 | 新增预算协议与 Skill 执行章节，定义默认文件/字节预算、扩展理由与审批条件 | 提示词协议已实现；CLI 尚不拦截 IDE 的真实文件读取 |
| G051-03 | 工具失败降级 | 采纳 | 分类工具缺失、超时、权限拒绝、非零退出、解析失败和环境缺失 | 协议已实现；各 IDE 工具调用需各自接入 |
| G051-04 | 轻量动态评测 | 采纳、分阶段 | 新增 fixture Mock Runner 与 6 个 P0 冒烟夹具 | 已运行夹具测试；不调用模型、不代表真实模型效果 |
| ENG-01 | CLI 命令契约回归 | 采纳 | 新增命令契约测试和新增命令解析测试，保留旧命令回归 | 当前测试覆盖关键命令与现有单元测试；后续应扩展全契约黑盒矩阵 |
| ENG-02 | Schema 错误可诊断 | 采纳 | YAML/JSON 解析错误包含行列和修改建议 | 结构业务错误仍由各 validator 按 findings 报告；并非所有 Schema 都采用外部 JSON Schema 引擎 |
| ENG-03 | 交互式向导 | 部分采纳/延期 | 保留现有 `aimes init` 交互式工具选择 | 多步骤项目/评测集/知识资产向导延期，避免本轮范围失控 |
| ENG-04 | V1.3 Skill 模块化 | 采纳为架构约束 | 明确注册/校验/加载/执行/验证边界，保留 V1.3 设计基线 | 本版本未实现完整动态执行或自动多 Skill 编排引擎 |
| ENG-05 | 审计追踪 | 部分实现 | 新增 JSONL append/validate、`run_id`、敏感字段脱敏 | 调用方显式记录；非自动全量采集；不具备防篡改保证 |
| ENG-06 | v0.3 兼容技术债 | 采纳为治理任务 | 明确生命周期盘点原则和退出门槛 | 未删除旧模块；删除前需依赖与兼容性证据 |

## 3. 本版本验收范围

1. 原有测试不退化；新增测试覆盖 Mock Runner、审计脱敏、审计结构校验、命令解析和友好解析错误。
2. 七个 Skills 仍通过注册表校验，真实工具验证状态继续为 `UNKNOWN`。
3. 14 个评测案例结构校验通过。
4. 6 个 P0 fixture 案例的字面检查通过；至少有一个负向测试证明缺少必要短语时 Runner 会失败。
5. wheel 可构建，并在隔离目标目录完成安装/版本冒烟。
6. 生成全量源码包、提示词资产包、复审报告、交付说明和 SHA-256 清单。

## 4. 明确不作的承诺

- 不宣称 Mock Runner 测量真实模型准确率、语义契约符合率或提示词提升幅度。
- 不宣称 IDE 中的文件读取已由预算协议强制拦截。
- 不宣称审计日志自动收集所有模型/IDE 活动或具备防篡改能力。
- 不宣称 Windows 11 或任何真实 IDE/Agent 运行时已验证。
- 不在缺少依赖证据时删除 V0.3 兼容模块。

## 5. 后续路线

- V0.5.x：扩大命令契约黑盒测试；增加计划文件的结构校验；补充更完整的 schema 错误定位；评估 `aimes init` 多步骤向导。
- V0.6：在用户明确选择模型提供方并配置凭据后，设计可插拔模型适配器与真实模型评测；输出脱敏、限流、成本和失败策略必须先行。
- V1.3：按 Skill 生命周期规范逐步实现动态注册、校验、受控加载、执行路由和输出验证；不允许未审查的 Skill 文本直接获得任意命令执行权限。
