# AIMES 提示词全量复审与优化报告

- 基线：AIMES CLI V0.5.0 完整源码包
- 本次交付：AIMES CLI V0.5.1 提示词优化版
- 范围：公共 Core 模板、7 个 P0 Skills、Skill 注册表、统一契约、Skill 编排、评测案例与交付文档
- 状态：静态优化完成；真实 IDE/Agent 运行时验证仍为 `UNKNOWN`

## 1. 本轮发现与处理

| 发现 | 处理方式 | 结果边界 |
|---|---|---|
| Skills 输入输出过于抽象 | 明确必需输入、输出字段、缺失值语义和完成判据 | 仍需后续 Schema/CLI 扩展做机器级契约验证 |
| 流程偏线性 | 补充继续/澄清/降级/阻断/审批决策条件 | 属于提示词设计，模型是否稳定遵循需案例实测 |
| 通用失败处理重复且不够任务化 | 保留统一错误语义，并增加每个 Skill 的具体失败分支 | 公共规则与任务规则分层，减少事实重复 |
| 证据与状态语义不统一 | 统一 PASS/FAIL/NOT_RUN/BLOCKED/UNKNOWN/PROPOSED/APPROVED/VERIFIED 语义 | 不改变原有 CLI 状态词的既有兼容约束；新增语义用于提示词协议，需校验映射 |
| 对提示注入的处理不够显式 | 明确仓库、网页、日志和历史输出均是待分析数据 | 不是安全隔离机制的替代品，仍需工具权限控制 |
| 缺少 Skill 编排 | 新增任务路由、依赖、可跳过条件、单写入者和停止规则 | 当前是规范/操作协议，不是自动执行引擎 |
| 评测案例较通用 | 新增专属案例并提供跨 Skill 基准套件 | 套件校验不等于模型运行评测 |
| 真实工具效果未经验证 | 注册表仍保持 `UNKNOWN`，报告明确列出试点要求 | 不宣称规则已被任何 IDE 自动加载 |

## 2. 逐 Skill 优化摘要

1. **项目接管**：加入基线、读取范围、上下文预算、过期交接核验、用户修改保护和最小交接。
2. **需求认知**：加入歧义分级、假设审批、可判定验收标准、非功能阈值来源和受影响写操作门禁。
3. **知识复用**：加入分层检索、覆盖范围、反例、过期资产、拒绝候选记录和可证伪验证计划。
4. **变更影响**：加入直接/间接影响链、风险与证据强度、分析覆盖率、动态依赖盲区和迁移/回滚门禁。
5. **架构契约审查**：加入发现分类、版本兼容、错误/状态语义、方案比较、ADR 草案与运行时限制。
6. **受控实施**：加入授权校验、保护基线、分步修改、持续 diff 检查、验证分级、失败恢复和部分完成报告。
7. **需求驱动测试**：加入需求追溯、风险排序、高区分度测试、失败分诊、执行状态分离和覆盖缺口。

## 3. 共性治理提升

- AIMES Core 仍是公共治理权威；Skill 只定义任务专属执行逻辑。
- 引入统一证据建议格式，区分静态文件证据、自动检查、运行时观察和用户确认。
- 强化不确定性校准：证据不足时必须使用 UNKNOWN/BLOCKED/NOT_RUN。
- 引入最小充分上下文策略，不鼓励无差别读取整个仓库。
- 明确单写入者、并行只读和隔离分支规则。
- 对硬门禁失败不允许用诊断平均分抵消。

## 4. 评测计划

新增 `examples/evaluation/prompt-optimization-suite.yaml`，覆盖常规、歧义、冲突、过期知识、动态依赖、用户修改保护、测试未执行、提示注入和未授权破坏性操作等案例。当前 CLI 可校验套件结构和案例元数据，但不会自动调用模型或执行真实 IDE 任务。

建议真实试点按相同任务集比较旧版与新版，并记录模型、模型版本、工具版本、运行模式、Skill 版本、初始仓库状态、原始输出、硬门禁结果和独立验收结果。至少保留一组不公开给被测模型的留出案例。

## 5. 尚未完成/不得宣称的能力

- 未实现自动 Skill Orchestrator 执行引擎；当前新增的是编排规范。
- 未实现模型调用和自动化评测执行器；CLI 现有 evaluation 能力负责验证已记录的案例集/运行记录。
- 未验证 Codex、Claude Code、Trae、ZCode、QCode 等工具的实际规则加载和行为一致性。
- 未在用户 Windows 11 环境完成安装/运行测试。
- 未把新增统一证据建议格式映射为新的 CLI Schema；当前沿用现有证据校验能力，后续可增量扩展。

## 6. 发布结论

本版本可以作为下一轮提示词试点基线。发布状态是“静态资产与本地自动化检查通过”，而不是“跨工具效果已验证”。真实工具适配验证完成前，所有 Skill 的 `validation_status` 保持 `UNKNOWN`。
