# Skill：产品分析与决策支持

## 目标与边界
为产品机会、市场进入、产品定位和体验改进提供可追溯的证据分析。本 Skill 是方法选择与编排入口，不要求每次执行所有分析方法，不替代业务责任人的决策或批准。

## 触发条件
产品分析、市场/竞品研究、市场进入、行业结构、战略定位、客户旅程、机会发现、方案优先级。

## 方法选择
- 市场/竞品/行业/市场进入：按需使用市场边界定义、波特五力、PESTEL、SWOT、竞品能力/定价/定位比较。
- 产品定位/战略方向：明确目标客户、未满足需求、替代方案、差异化证据、战略选项和权衡。
- 客户体验/旅程：绘制用户角色、阶段、行为、想法/感受、痛点、机会；区分真实研究证据与假设。
- 机会发现/方案优先级：从用户问题和机会出发，再形成候选方案与实验；可用 RICE/WSJF 等排序，但必须披露评分口径和不确定性。
- 跨域任务：只组合对当前决策有贡献的方法，说明为何选择或跳过其他方法。

## 工作流程
1. 定义要支持的决策、分析对象、用户/市场、地域、时间范围和交付对象；缺项标记 UNKNOWN 并判断是否阻断。
2. 建立证据台账，将结论标注为 Fact、Inference 或 Assumption。事实需记录来源、日期和可复核位置；无来源不得声称已验证。
3. 分析市场/用户/竞品/内部能力时，说明覆盖范围、数据质量、时效和检索盲区；不把单一来源当作完整市场事实。
4. 形成关键发现、因果逻辑、机会、选项及权衡，区分事实结论与策略判断。
5. 对重要假设提出验证实验、所需数据、成功判据和负责人；不得伪造访谈、市场规模、竞争对手数据或来源。
6. 给出决策建议与替代选项；明确哪些决定需产品/业务责任人批准。
7. 记录风险、开放问题、下一步和复审触发条件。

## 必需输出
- analysis_scope：目标决策、分析边界、对象与时间范围。
- evidence_ledger：主张、标签、来源/日期、可靠性、限制。
- key_findings：发现、影响、证据与置信度。
- options_and_tradeoffs：候选方案、收益、成本、风险与依赖。
- open_questions：未知、假设、验证方法与责任人。
- decision_recommendation：建议、理由、替代项、批准门禁和下一步。

## 失败处理与完成判据
缺少当前数据访问能力时，标记未执行的研究并提出验证计划；不得伪造网页搜索或来源。输入缺失时说明范围限制；关键数据不可靠时降低结论强度。输出必须区分事实、推断和假设，并披露覆盖范围与盲区。状态只能是证据支持的 PASS、NOT_RUN、BLOCKED 或 UNKNOWN。
